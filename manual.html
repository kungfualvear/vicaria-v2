Introducción

ViCaRiA es una aplicación de monitoreo de caudales diseñada para mostrar en tiempo real lecturas de sensores, proporcionar alertas configurables y ofrecer un tablero con tarjetas por cada punto de medición.

Este manual explica cómo instalar ViCaRiA, usar el tablero, configurar alarmas y resolver problemas frecuentes.

Instalar / Abrir

Desde móvil (Android): Abrir la web en Chrome → menú ⋮ → "Agregar a pantalla principal" o cuando aparezca la opción "Instalar". En dispositivos compatibles la app se abre en ventana independiente.

Desde desktop (Chrome/Edge): Abrir la web, comprobar que el icono de instalar aparece en la barra de direcciones o en el menú (⋮) → "Instalar ViCaRiA". Si no aparece: ver sección de resolución de problemas.

Abrir sin instalar: Acceder a la URL www.vicaria.netlify.app.

Uso diario

Al ingresar verás el tablero principal con tarjetas. Cada tarjeta representa un punto de medición. En la barra superior encontrarás:

  • Búsqueda: filtra tarjetas visibles por código o nombre.
  • Filtros: ver todas / favoritos / solo alarmas.
  • Gestionar Códigos: abre un modal para seleccionar qué tarjetas mostrar.
  • Actualizar: fuerza una consulta al servidor para refrescar datos.

Lectura de una tarjeta:

  • Nombre / código: título de la tarjeta.
  • Valor principal: caudal o altura según configuración.
  • Información secundaria: valor secundario, caudal asignado y variación.
  • Última actualización: fecha y hora de la última medición; si aparece ⚠️ el dato está desactualizado.

Tarjetas y configuración

Haz clic en la tarjeta para expandir la configuración. Opciones principales:

  • Nombre personalizado: cambio permanente para mostrar en el tablero.
  • Favorito: marca la tarjeta para filtros rápidos.
  • Parámetro principal: elegir entre usar caudal (l/s) o altura (cm).
  • Caudal / Altura asignado: valor de referencia usado para calcular la variación.
  • Umbrales: valores arriba/abajo para disparar alarmas.
  • Alarmas: activar/desactivar notificaciones y sonido.
  • Ciclos de alarma: número de ciclos necesarios antes de iniciar la alarma.
  • Orden de visualización: cambiar posición de la tarjeta en el tablero.

Los cambios se guardan localmente en el navegador (localStorage). Si usas otro dispositivo o borrás datos, los ajustes no se sincronizan a menos que el administrador lo implemente.

Alarmas

ViCaRiA puede emitir:

  • Notificación del navegador (si el usuario autorizó permisos).
  • Tono sonoro repetido (si el dispositivo y navegador lo permiten).

Reglas básicas:

  • Si la variación supera el umbral superior durante los ciclos configurados, se dispara alarma de aumento.
  • Si la variación supera el umbral inferior (merma) durante los ciclos, se dispara alarma de merma.

Cómo silenciar una alarma:

  • Dentro de la tarjeta expandida, presioná Silenciar Alarma (si está activo).
  • Desactivar la casilla de alarma en la configuración de la tarjeta.

Nota: en iOS las notificaciones web están limitadas; la alarma sonora puede no funcionar correctamente en todos los navegadores móviles.

Preguntas frecuentes (FAQ)

¿Por qué veo datos antiguos?

Si aparece el icono ⚠️ en "Última actualización" significa que la medición tiene al menos 30 minutos de antigüedad.

¿Se sincronizan las preferencias entre dispositivos?

No. Las preferencias se guardan en el almacenamiento del navegador.

¿Cómo agrego o elimino tarjetas?

Ir a "Gestionar Códigos" → buscar el código → marcar o desmarcar la casilla → "Guardar Selección".
